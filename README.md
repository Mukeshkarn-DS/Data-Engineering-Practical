# Data Engineering Practicals 01–10

A clean academic repository containing **Data Engineering Practicals 01 through 10** by **Mukesh Karn**.

## Practical Index

| Practical | Topic | Main Technologies |
|---|---|---|
| 01 | Data parsing, anomaly checks, binary/pickle files, regex, SQLite CRUD | Python, SQLite |
| 02 | Retail sales dashboard | Power BI, Excel |
| 03 | MongoDB document operations | MongoDB |
| 04 | Noise elimination, feature selection and EDA | Python, Jupyter |
| 05 | API and CSV data extraction | Python, Pandas, Requests |
| 06 | ETL workflow orchestration | Apache Airflow |
| 07 | CSV/JSON ETL with incremental loading | Python, Pandas, SQLite |
| 08 | CSV processing with Spark DataFrames | PySpark |
| 09 | Incremental e-commerce ETL | Python, Pandas, SQLite, unittest |
| 10 | End-to-end star-schema ETL | Python, Pandas, SQLite, unittest |

## General Notes

- Read the `README.md` inside each practical before running it.
- Some practicals require external software such as Power BI, MongoDB, Airflow, Java/Spark, or Jupyter.
- Generated databases, reports, dashboards, and cache files are not treated as source code when they can be recreated by the practical.
- The original practical logic has not been rewritten as part of this cleanup.
