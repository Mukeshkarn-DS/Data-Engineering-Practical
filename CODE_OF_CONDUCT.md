# Code of Conduct

## Our Commitment

We are committed to providing a respectful, inclusive, and harassment-free learning environment for everyone.

## Expected Behavior

- Be respectful and constructive in issues and pull requests.
- Give actionable feedback tied to repository content.
- Assume positive intent while discussing improvements.

## Unacceptable Behavior

- Harassment, insults, or discriminatory language.
- Doxxing or sharing private information.
- Bad-faith technical discussions or spam.

## Enforcement

Project maintainers may remove, edit, or reject contributions that violate this Code of Conduct.

## Reporting

If you experience or witness unacceptable behavior, open a private security report where appropriate or contact the maintainer through GitHub.
