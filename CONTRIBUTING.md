# Contributing

Thanks for your interest in improving this learning repository.

## Scope for contributions

- Improve documentation clarity and correctness.
- Add reproducible, practical-specific setup notes.
- Propose non-destructive quality checks.
- Fix bugs in practical scripts only when aligned with practical objectives.

## Ground rules

1. Preserve all existing practical folders and original naming.
2. Do not delete/rename coursework artifacts (datasets, screenshots, DB files, notebooks, PBIX, DOCX, generated outputs).
3. Keep pull requests focused and small.
4. Use factual language: avoid claiming tests or execution that were not run.

## Development workflow

1. Create a feature branch from `main`.
2. Make focused edits.
3. Run targeted local checks relevant to your change.
4. Open a PR with:
   - Scope summary
   - Files changed
   - Validation performed
   - Remaining limitations

## Commit style

Prefer Conventional Commits, for example:

- `docs: improve practical-07 execution guide`
- `chore: add repository-level editorconfig`
- `fix: correct broken relative link in root readme`

## Code and docs standards

- UTF-8 text, LF line endings, final newline.
- Keep Markdown links relative when pointing inside this repository.
- Do not introduce fake metrics, fake badges, or invented results.
